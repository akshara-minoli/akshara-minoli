A cloud-native microservices platform for reporting and managing urban infrastructure issues, built primarily as a **DevOps / Cloud / SRE portfolio project**.

### DevOps & SRE Highlights

- Architected **six Node.js/Express microservices** with a PostgreSQL database-per-service design.
- Containerized application services using **Docker** and Docker Compose.
- Built **Jenkins CI/CD pipelines** for automated testing, Docker builds, security scanning, and image publishing to **GHCR**.
